# 驗證設計 — APIGatewayMQ

> 衝突以 [APIGatewayMQ 規格書.md](../APIGatewayMQ%20規格書.md)、[API規格書.md](../API規格書.md) 為準。  
> 規範：EngineeringOS `knowledge/validation-design.md`  
> 本專案**無 JWT／角色授權**；L1 以限流與傳輸為主。

## 1. 四層驗證

| 層 | 機制 | 典型失敗 |
|----|------|----------|
| L1 傳輸／限流 | `Content-Type`、`RateLimitWebFilter`（Redis 固定窗口） | 429 `RATE_LIMIT_EXCEEDED`；Kafka 失敗 503 |
| L2 格式 | Gateway／Engine DTO 驗證（quantity／price／side） | 400 `VALIDATION_FAILED` |
| L3 業務 | `RiskEngine` 規則鏈、狀態機（取消／補成交） | 422 `RISK_*`；409 `DUPLICATE_ORDER`；404 |
| L4 資料 | `client_order_id` UNIQUE 等 DB 約束 | 409／內部錯誤（應少見；冪等優先在 L3） |

## 2. 權限矩陣

| 端點 | 公開 | 說明 |
|------|------|------|
| `POST /api/v1/orders`（Gateway） | 是 | 限流保護；無登入 |
| `GET/PATCH/POST /api/v1/**`（經 Gateway 代理） | 是 | Round-Robin 至 Engine |
| Engine 直連 `:8081` | 是（除錯） | 同步下單 201；非正式對外 |

無 USER／ADMIN 角色模型。

## 3. 錯誤碼

| 情境 | HTTP | errorCode |
|------|------|-----------|
| 欄位驗證失敗 | 400 | `VALIDATION_FAILED` |
| 訂單／持倉不存在 | 404 | `ORDER_NOT_FOUND`／`POSITION_NOT_FOUND` |
| 方法不允許 | 405 | `METHOD_NOT_ALLOWED` |
| 冪等重複 | 409 | `DUPLICATE_ORDER` |
| 風控拒絕 | 422 | `RISK_POSITION_LIMIT` 等（R001~R009） |
| Gateway 限流 | 429 | `RATE_LIMIT_EXCEEDED` |
| Kafka 發送失敗 | 503 | （見 API 規格） |
| 內部錯誤 | 500 | `INTERNAL_ERROR` |

風控對照表見 [API規格書.md](../API規格書.md)「風控 errorCode 對照」。R010 為縮量非拒絕。

## 4. 對照程式

| 角色 | 類別 |
|------|------|
| Gateway 限流 | `RateLimitWebFilter` |
| Gateway 下單 | `OrderSubmitController` |
| Engine Handler | `GlobalExceptionHandler` |
| 錯誤碼常數 | `ErrorCodes` |
| 風控 | `RiskEngine` + `*Rule` |
