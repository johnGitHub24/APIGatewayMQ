APIGatewayMQ — API 文件

非同步下單削峰 · Kafka Consumer Group · 冪等 · 風控／狀態機 · gateway（WebFlux :8080）+ engine（:8081／多副本）· Redis 限流 · PostgreSQL

CodeGraphic API 規格書 architecture Gateway Swagger（:8080） Engine Swagger（:8081）

啟動與位址

啟動先起基礎設施（Kafka／Redis／PostgreSQL，Docker），再 .\gradlew.bat :engine:bootRun、:gateway:bootRun
gateway:8080（WebFlux）· JSON /v3/api-docs
engine:8081（可多副本，第二副本常用 :8082）· JSON /v3/api-docs
驗證.\scripts\check.ps1（= gradlew check，unit + integration）

API 分組（實際 Controller）

  • Gateway 下單：POST /api/v1/orders（202 進 Kafka 削峰；Redis 限流）
  • Gateway 代理：GET /api/v1/** 轉發 Engine；POST /api/v1/orders/{id}/fill、PATCH /api/v1/orders/{id}/cancel
  • Engine Orders：POST/GET /api/v1/orders、GET /{orderId}、GET ?clientOrderId=...、GET /{orderId}/events、POST /{orderId}/fill、PATCH /{orderId}/cancel
  • Engine 查詢：GET /api/v1/trades／/{tradeId}、GET /api/v1/positions／/{symbol}、GET /api/v1/pnl
  • Engine Jobs：POST /api/v1/jobs/stale-order-cancellation／pnl-snapshot／failed-command-retry／cleanup、GET /api/v1/pnl-snapshots、GET /api/v1/failed-commands

認證與範例流程

  • 無認證（無 Spring Security／JWT）；Gateway 有 Redis 限流（預設 50 req/s）。
  • 冪等：下單帶 clientOrderId，重送同 id 不重複建單。
  • 範例：POST :8080/api/v1/orders（202 ACCEPTED，訊息進 Kafka）→ Engine 消費落庫 → GET :8080/api/v1/orders?clientOrderId=... 查最終狀態 → POST /{id}/fill、GET /api/v1/pnl。

右上下拉可切換 Gateway／Engine 的 live /v3/api-docs（需先啟動服務），以及 docs 內的靜態 yaml 匯出／規格（免啟動可看）。 若以 file:// 直接開啟本頁，live 來源會因 CORS 無法載入，請改用各服務 /swagger-ui.html，或在 docs 目錄啟一個靜態伺服器（例如 python -m http.server）。
