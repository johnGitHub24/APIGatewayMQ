# 資料庫設計 — APIGatewayMQ

> 衝突以 [APIGatewayMQ 規格書.md](../APIGatewayMQ%20規格書.md) 第 3 章為準。  
> 規範：EngineeringOS `knowledge/database-design.md`

## 1. 存取鏈

```text
Gateway（讀代理）→ Engine Controller → TradingService (@Transactional)
  → Repository → PostgreSQL（Docker）／H2（test）
Kafka Consumer → TradingService → 同上
```

Gateway **不**直接寫 DB；持久化只在 Engine。

## 2. 資料表

腳本：[sql/schema.sql](sql/schema.sql)（對齊 Trading System MVP schema，並含 Job 擴充表）

| 表 | 用途 | 重要約束／索引 |
|----|------|----------------|
| `orders` | 訂單主檔 | `client_order_id` UNIQUE；`idx_orders_symbol_created` |
| `trades` | 成交 | FK → `orders(id)` |
| `positions` | 持倉 | `symbol` UNIQUE |
| `order_events` | 審計日誌 | `(order_id, created_at)` |
| `pnl_snapshots` | JOB-B 日結快照 | `(snapshot_date, symbol)` |
| `failed_commands` | JOB-C DLQ | `(status, next_retry_at)` |

整合測試：`DatabaseSchemaIntegrationTest.DB_001_allFourTablesExist`（核心四表）。

## 4. 環境

| Profile／環境 | DB | 設定 |
|---------------|-----|------|
| Docker 全棧 | PostgreSQL（compose，對外常為 5433） | `SPRING_DATASOURCE_*` |
| 本機 Engine 預設 | PostgreSQL `localhost:5432/trading` | `engine/.../application.yml` |
| 測試 | H2（Embedded／JPA `ddl-auto`） | 測試設定 |

## 5. SQL 驗證

```sql
-- PostgreSQL / H2（表名大小寫依方言調整）
SELECT TABLE_NAME FROM INFORMATION_SCHEMA.TABLES
WHERE UPPER(TABLE_NAME) IN (
  'ORDERS','TRADES','POSITIONS','ORDER_EVENTS','PNL_SNAPSHOTS','FAILED_COMMANDS'
);

-- 冪等約束
-- SHOW INDEX / 確認 client_order_id UNIQUE
```
