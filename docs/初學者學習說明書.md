## 0. 30 秒理解本專案

```text
限流入口 → 202 快速回應 → Kafka 削峰 → Engine 風控成交 → 輪詢查結果
```

與 MVP 的最大差異：**下單走 Gateway 回 202（非同步）**，不再等 Engine 跑完才回應。

**學習建議：** 先用 §2 IntelliJ + H2 跑通 Engine REST，再 §3 Docker 全棧體驗 202／Kafka。

## 2. 最快上手：IntelliJ + H2（不用 Docker）

Engine 預設 profile = **`local`**：

- DB = **H2 記憶體**（不必 PostgreSQL）
- **Kafka Listener 關閉**（不必本機 Kafka）
- 用 **同步 REST** 學下單／風控／持倉
- 啟動成功後 Console 會印 `StartupInfoLogger` 連結框

### 步驟

1. 開啟 `engine` 模組，執行 `com.trading.engine.TradingEngineApplication`  
   （Active profiles **留空**即可；不要設 `docker`）
2. 等 Console 出現框線「已啟動 — 使用連結」
3. 瀏覽器開：http://localhost:8081/swagger-ui.html
4. 呼叫 `POST /api/v1/orders`，再 `GET /api/v1/positions`、`GET /api/v1/pnl`

Gradle 等效：

```powershell
cd "D:\ClaudeCode\APIGatewayMQ"
.\gradlew.bat :engine:bootRun
```

### 常見錯誤（你剛剛踩到的）

| 現象 | 原因 | 處理 |
|------|------|------|
| `PSQLException`／嘗試連線已失敗 | 連 PostgreSQL `:5433` 但 Docker 沒開 | 確認 Active profiles 為空／`local`；不要設 `docker` |
| 埠 8081 被占用 | 舊 Engine 還在跑 | 停掉舊行程後重啟 |
| 想學 202／Kafka | local 故意關掉 Consumer | 改走 §3 Docker 全棧 |

H2 Console：http://localhost:8081/h2-console（JDBC URL 見啟動框；帳號 `sa`、密碼空白）

> **local 學到什麼／學不到什麼**  
> 學到：Engine 風控、訂單狀態、Swagger、持倉 PnL。  
> 學不到：Gateway 202、Kafka 削峰、Redis 限流、多副本——那些在 §3。

## 4. 第一次下單（經 Gateway，需 §3）

### Step 1：非同步下單（經 Gateway）

```http
POST http://localhost:8080/api/v1/orders
Content-Type: application/json
Idempotency-Key: my-first-order

{
  "symbol": "BTCUSDT",
  "side": "BUY",
  "quantity": 0.5,
  "price": 65000
}
```

預期回應：**202 Accepted**

```json
{
  "commandId": "550e8400-...",
  "status": "ACCEPTED",
  "clientOrderId": "my-first-order",
  "message": "Order queued for processing",
  "pollUrl": "/api/v1/orders?clientOrderId=my-first-order",
  "acceptedAt": "2026-07-06T13:00:00Z"
}
```

> **重點：** 202 只代表「已排進 Kafka」，不代表訂單已成交。必須用 `pollUrl` 輪詢。

### Step 2：輪詢結果

```http
GET http://localhost:8080/api/v1/orders?clientOrderId=my-first-order
```

等待 1～3 秒後重試，直到看到 `status: "FILLED"` 或 `"REJECTED"`。

```json
{
  "clientOrderId": "my-first-order",
  "symbol": "BTCUSDT",
  "status": "FILLED",
  "quantity": 0.5,
  "filledQuantity": 0.5
}
```

### Step 3：查持倉與損益

```http
GET http://localhost:8080/api/v1/positions
GET http://localhost:8080/api/v1/pnl
```

### PowerShell 一鍵測試（Invoke-RestMethod）

```powershell
$headers = @{ "Idempotency-Key" = "ps-demo-001" }
$body = '{"symbol":"BTCUSDT","side":"BUY","quantity":0.5,"price":65000}'
Invoke-RestMethod -Method POST -Uri "http://localhost:8080/api/v1/orders" `
  -Headers $headers -ContentType "application/json" -Body $body

Start-Sleep -Seconds 2
Invoke-RestMethod -Uri "http://localhost:8080/api/v1/orders?clientOrderId=ps-demo-001"
```

## 5. 常見問題

| 症狀 | 可能原因 | 處理方式 |
|------|----------|----------|
| IntelliJ Engine 連不上 DB | 誤用 docker／PostgreSQL | 改用 §2 local/H2 |
| `docker info` 失敗 | Docker Desktop 未啟動 | 開啟 Docker Desktop 後重試 |
| 202 後輪詢一直 404 | Engine 尚未消費完 | 等 2～5 秒再輪詢 |
| 429 Too Many Requests | 超過限流（預設 100 req/s） | 等 1 秒後重試；見 `Retry-After` Header |
| 409 Conflict | 同一 Idempotency-Key 重複下單 | 預期行為（冪等保護） |
| 422 Unprocessable | 風控拒絕 | 檢查 `errorCode`、`ruleCode` |
| 連不上 8080 | Gateway 容器未啟動 | `docker compose ps` 檢查狀態 |

```powershell
docker compose up -d postgres redis zookeeper kafka

# Active profiles = docker，或：
.\gradlew.bat :engine:bootRun --args="--spring.profiles.active=docker --server.port=8081"

```
