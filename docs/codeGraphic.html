5 分鐘上手 — IntelliJ + H2（不用 Docker）

  • 預設 profile = local：記憶體 H2，不連 PostgreSQL。
  • Kafka Listener 關閉：先用 Engine 同步 REST 學風控／訂單。
  • 啟動成功後 Console 會印連結框（StartupInfoLogger）。
  • 學完再說 Docker 全棧（Gateway 202 + Kafka 削峰）。
  1. IntelliJ 開啟模組 engine，執行 TradingEngineApplication（不必設 Active profiles）。
  2. 看到框線輸出後，開 http://localhost:8081/swagger-ui.html。
  3. POST /api/v1/orders 下一筆單 → GET /api/v1/positions 看持倉。
  4. 可選：H2 Console http://localhost:8081/h2-console（JDBC 見 Console 框）。
  5. 下一步：讀「非同步下單」分頁，再 docker compose / scripts/start.ps1。

若出現「嘗試連線已失敗／PostgreSQL」：代表跑到 docker profile 或舊設定。清掉 Active profiles，或確認未設 SPRING_PROFILES_ACTIVE=docker。

非同步下單 — Gateway → Kafka

  • Gateway POST /api/v1/orders 回 202 + pollUrl。
  • Producer 寫入 topic order.commands（key=symbol）。
  • Engine Consumer Group trading-engine 分攤 partition。
  • 冪等 Idempotency-Key → client_order_id UNIQUE。
sequenceDiagram participant C as Client participant G as Gateway :8080 participant K as Kafka participant E as Engine :8081 C->>G: POST orders G->>K: order.commands G-->>C: 202 pollUrl K->>E: OrderCommandConsumer E->>E: TradingService.placeOrder

這條路需要 Docker infra。local/H2 先用 Engine 直連 REST 對照理解。

限流 — Redis 固定窗口

  • RateLimitWebFilter WebFlux 前置過濾。
  • 超限回 429 Too Many Requests。
  • Redis 故障 fail-open（放行）。
  • Prometheus 監控 Gateway 指標。

Engine — 消費與交易

  • engine 模組 :8081／:8082 多副本。
  • TradingService + RiskEngine 同 MVP 語意。
  • DB：local=H2；docker=PostgreSQL。
  • 同步 REST 供學習／除錯；Kafka Consumer 在 docker 模式開啟。

  • gateway：WebFlux、限流、Producer、讀代理。
  • engine：Consumer、application、domain、infrastructure。
  • 驗證：.\scripts\check.ps1。
