非同步下單 — Gateway → Kafka

  • Gateway POST /api/v1/orders 回 202 + pollUrl。
  • Producer 寫入 topic order.commands（key=symbol）。
  • Engine Consumer Group trading-engine 分攤 partition。
  • 冪等 Idempotency-Key → client_order_id UNIQUE。

限流 — Redis 固定窗口

  • RateLimitWebFilter WebFlux 前置過濾。
  • 超限回 429 Too Many Requests。
  • Redis 故障 fail-open（放行）。
  • Prometheus 監控 Gateway 指標。
